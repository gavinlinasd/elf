# elf

An [OpenClaw](https://openclaw.com) skill for managing async job queues.

## About

This skill teaches an OpenClaw agent to enqueue, monitor, retry, and cancel long-running tasks using a local job queue.

See [PLAN.md](PLAN.md) for the full design and execution plan.
